=======================================
CRM Lead: Membership Application Fields
=======================================

* Adds generic fields to be used when website form responses are 
  used to gather applications for membership.
* Use case is separating important info into their own fields 
  so that Odoo's search/filtering features can be used to 
  manage the applications i.e. leads.

  * Organization info:  
  
    * Company Registry
    * Year Established
    * Director's Name

  * Billing info:

    * edicode
    * eInvoice Operator
    * Invoice e-mail address

Configuration
=============
* Configure your website form to map inputs to the relevant
  fields.

Known issues / Roadmap
======================

  but adding very niche / customer-specific ones should be avoided.
