==============================
CRM – Force to use Opportunity
==============================

::

    However are the settings done, this module forces to use Opportunity
    type on created Leads.

Configuration
=============
::

    None needed

Usage
=====
::

    Create a new lead to see that it is created as an Opportunity

Known issues / Roadmap
======================
::

    The module overrides any conditions to assign if a new lead
    is 'lead' or 'opportunity'. This is not dangerous, but this
    can be disables only by uninstalling this module.
