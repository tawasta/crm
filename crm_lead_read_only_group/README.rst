==========================
CRM Lead Read Only Group
==========================

Adds a new access group, *CRM Lead: Read Only*, that can only read
``crm.lead`` records (leads/opportunities) - no create, edit or delete
rights.

Configuration
=============

Assign the *CRM Lead: Read Only* group to a user under
**Settings → Users & Companies → Users → [user] → Access Rights**, in the
*Sales* section.
