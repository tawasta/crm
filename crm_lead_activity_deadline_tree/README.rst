=============================
CRM Activity Deadline in List
=============================

Adds the `activity_date_deadline` field to the CRM opportunity list view (`crm.lead`),
so that users (e.g. managers) can see the next scheduled activity deadline regardless of the assigned user.

Configuration
=============
* None needed

Usage
=====
View the deadline of the next activity for each lead in the list view.
