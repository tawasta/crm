==========================
CRM Lead: Education Levels
==========================

* Adds to leads the fields "Education Levels" 
  from ``res_partner_education_level`` and "Other Education or Degree".
* Intended e.g. for membership applications from a website form, where
  the applicant can select several degrees or qualifications.


Configuration
=============
* Create the education levels in Contacts > Configuration > Education
  level.

Usage
=====
* See the new fields on the "Education" tab of the lead form.

Known issues / Roadmap
======================
* Note that partner currently only have a single education level
  whereas leads support multiple ones.
