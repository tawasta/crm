===================
CRM SharePoint Link
===================
This module adds a clickable SharePoint/Customer link field to the CRM Lead form.

The field is displayed directly after the "Tags" field on the CRM opportunity form view.  
It allows users to enter a URL (such as a SharePoint folder) and access it with a single click.

Features
========
* Adds a new `sharepoint_link` field to `crm.lead`
* Displays the field as a clickable URL
* Field label: **SharePoint / Customer**

Configuration
=============
No special configuration required. Just install the module.

Usage
=====
1. Go to *CRM > Sales > Opportunities*
2. Open or create a lead.
3. Fill in the **SharePoint / Customer** field with a valid URL (e.g., `https://sharepoint.com/customer123`)
4. Click the link to open the SharePoint location.
