========================
CRM Lead – Delivery Date
========================

Adds Delivery Date to lead/opportunity

Configuration
=============
No special configuration is required since the module only adds an informative field.

Usage
=====
Install the module and select a lead record. Then fill in Delivery Date info.

Known issues / Roadmap
======================
A user should not expect any issues with the module. Only possible problem is if there
already exist delivery_date -field with different attributes.
